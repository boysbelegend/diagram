About

Information about the extension

Mermaid Diagram Editor & Viewer

v1.0.0

A powerful Chrome/Edge extension for creating, editing, and viewing Mermaid diagrams with live preview support for flowcharts, sequence diagrams, class diagrams, C4 diagrams, and more.

Features

  • ✨ Live preview editor
  • 📊 Support for 9+ diagram types
  • 🎨 Dark mode support
  • 💾 Local storage
  • 📤 Export to PNG, SVG, and more
  • 🌐 Auto-render on web pages
